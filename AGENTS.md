# Agent guidance

- Read [CONTRIBUTING.md](CONTRIBUTING.md) before making changes.
- Follow [RELEASE.md](RELEASE.md) when preparing or publishing a version.
- Maintain [CHANGELOG.md](CHANGELOG.md) as user-visible net changes since the previous release. Exclude development history, CI, tests, and internal maintenance tooling. Keep unpublished changes under `Unreleased`; rolling nightly release notes include the entire section.
- Use English for project artifacts and keep [README.zh-CN.md](README.zh-CN.md) aligned with [README.md](README.md).
